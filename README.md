# Syed Muneeb Ur Rehman Bukhari - Portfolio

A modern, responsive single-page portfolio website showcasing my education, projects, experience, skills, certifications, and contact details as a Software Engineering student.

## Features

- **Modern Visual Design**: Clean glass-like cards, strong typography, and responsive spacing
- **Responsive Navigation**: Sticky header with mobile menu support
- **Single-Page Architecture**: Smooth scrolling between sections
- **Rich Content Sections**: Education, Projects, Demos, Experience, Skills, Learning, Certifications, Hobbies, and Contact
- **Responsive Media**: Optimized for desktop, tablet, and mobile layouts
